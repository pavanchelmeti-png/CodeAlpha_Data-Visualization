# 📚 Books to Scrape – Price & Rating Analysis

## 📌 Project Overview

This project was completed as part of the **CodeAlpha Data Analytics Internship – Task 3: Data Visualization**.

The project uses **Microsoft Power BI** to create an interactive dashboard from the cleaned Books to Scrape dataset. The dashboard visualizes book prices, ratings, price distribution, and the relationship between price and rating.

## 🎯 Objectives

- Transform data into meaningful visualizations.
- Identify patterns and trends in book prices and ratings.
- Compare average prices across different ratings.
- Analyze the distribution of book prices.
- Explore the relationship between price and rating.
- Create an interactive and easy-to-understand dashboard.
- Present useful insights from the dataset.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- CSV
- Data Visualization

## 📊 Dataset

The dataset was originally collected from the **Books to Scrape** website using Python web scraping techniques in Task 1.

The data was then cleaned and analyzed in Task 2 before being used to create this Power BI dashboard.

### Main Columns

| Column | Description |
|---|---|
| Title | Name of the book |
| Price | Price of the book |
| Rating | Book rating from 1 to 5 |
| Availability | Availability status |
| URL | Original book webpage |

## 📈 Dashboard Components

### KPI Cards

The dashboard includes:

- **Total Books**
- **Average Price**
- **Average Rating**
- **Highest Price**

### Visualizations

**1. Books by Rating**  
Shows the number of books available for each rating.

**2. Average Price by Rating**  
Compares the average price of books across different ratings.

**3. Price Distribution**  
Shows how book prices are distributed across different price ranges.

**4. Price vs Rating**  
Shows the relationship between book price and rating.

**5. Rating Slicer**  
Allows users to filter the dashboard based on book rating.
